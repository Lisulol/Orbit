# Orbit

Space Tracker that tracks different information like:

-ISS location

- Weather on Mats
- Near Earth Objects
- Meteor Showers
- Upcoming Missions
- Astronomical Pictures
- Visible satellites based on your location

## Built With

- **[Next.js 15](https://nextjs.org/)**
- **[Tailwind CSS v4](https://tailwindcss.com/)**
- **[Shadcn](https://ui.shadcn.com/)**
- **[Tabler](https://tabler-icons.io/)**
- **[Three.js](https://threejs.org/)**
